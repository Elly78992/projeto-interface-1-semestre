# projeto-interface-1-semestre
 Redesign de Interface — Spotify

«Projeto acadêmico de UX/UI e Experiência do Usuário, desenvolvido durante o 1º semestre de Ciência da Computação.»

Sobre o projeto

Este projeto consiste em uma análise e proposta de redesign da interface do Spotify, com foco em melhorar a experiência do usuário, a usabilidade, a acessibilidade e a organização visual da plataforma.

Durante o desenvolvimento, foram analisados problemas relacionados à poluição visual, dificuldade de localização de algumas funções, excesso de recomendações e necessidade de uma navegação mais simples e eficiente.

A partir dessa análise, foi desenvolvido um protótipo de alta fidelidade, mantendo elementos da identidade visual do Spotify e propondo melhorias na arquitetura da informação e na interação do usuário.

Objetivos

- Melhorar a organização da interface;
- Reduzir a poluição visual;
- Facilitar o acesso às principais funções;
- Tornar a navegação mais intuitiva;
- Melhorar a acessibilidade;
- Reduzir a repetição das recomendações;
- Facilitar o acesso ao histórico de músicas;
- Aumentar a autonomia do usuário sobre sua biblioteca;
- Criar uma experiência mais adequada para dispositivos móveis.

Problemas identificados

Durante a análise da interface original, foram identificados principalmente:

- Excesso de elementos visuais na tela inicial;
- Muitos banners e recomendações competindo pela atenção;
- Dificuldade para encontrar algumas funções;
- Repetição de recomendações;
- Mudanças frequentes na posição de comandos;
- Dificuldade para acessar músicas ouvidas anteriormente;
- Necessidade de uma hierarquia visual mais clara.

Solução proposta

O redesign propõe uma interface mais limpa e organizada, com:

- Seção "Escutado Recentemente";
- Histórico de músicas reproduzidas;
- Recomendações mais variadas;
- Atalhos para playlists e músicas frequentes;
- Playlists favoritas fixadas no topo da Home;
- Biblioteca reorganizada;
- Busca mais acessível;
- Controles do player maiores;
- Melhor hierarquia visual;
- Redução de elementos desnecessários.

Busca rapidez e objetividade para encontrar músicas, playlists e podcasts.

Principais necessidades:

Principais necessidades:

Jornada e experiência do usuário

Foram analisados pontos de contato como:

- Tela inicial;
- Busca;
- Recomendações;
- Player musical;
- Playlists;
- Biblioteca.

Os principais pontos positivos identificados foram a rapidez da navegação, facilidade de localização dos comandos e conforto visual.

Entre os principais pontos críticos estavam a poluição visual, excesso de elementos e mudanças que poderiam quebrar a familiaridade do usuário com a interface.

 Estratégias de design

Mobile First

A interface foi pensada inicialmente para dispositivos móveis, priorizando:

- Navegação simples;
- Menor quantidade de cliques;
- Acesso rápido ao histórico;
- Funções principais ao alcance do usuário;
- Redução da poluição visual.

Offline First

A proposta considera o acesso a informações importantes mesmo sem conexão, como:

- Histórico recente;
- Playlists;
- Recomendações;
- Preferências de navegação.

UI Otimista

A interface foi planejada para fornecer respostas rápidas às ações do usuário, reduzindo a percepção de espera e tornando as interações mais fluidas.

 Design Visual

A proposta visual busca manter a identidade do Spotify, mas com uma organização mais limpa.

Paleta

- "#121212" — fundo principal;
- "#1DB954" — ações e elementos de destaque;
- "#FFFFFF" — títulos e informações principais;
- "#B3B3B3" — informações secundárias.

A interface utiliza tons de cinza para reduzir a poluição visual e o verde de forma estratégica para destacar ações importantes.

Acessibilidade

O projeto considerou princípios de acessibilidade baseados nas diretrizes WCAG 2.1 – Nível AA.

Foram consideradas melhorias como:

- Contraste entre texto e fundo;
- Hierarquia de informações;
- Ícones reconhecíveis;
- Áreas de toque ampliadas;
- Organização lógica da interface;
- Redução da sobrecarga cognitiva.

Protótipos

O projeto passou por diferentes níveis de prototipagem:

Baixa fidelidade

Utilizada para estruturar inicialmente a organização das telas e fluxos.

Média fidelidade

Utilizada para testar a arquitetura da informação e os principais componentes da interface.

Alta fidelidade

Utilizada para representar visualmente a proposta final de redesign, incluindo elementos visuais, componentes e interações.

Testes de usabilidade

Foram utilizados dois métodos principais:

Think-Aloud

Os usuários realizaram tarefas enquanto verbalizavam seus pensamentos, permitindo identificar dúvidas e pontos de hesitação.

Teste de 5 segundos

Utilizado para avaliar se a nova tela inicial apresentava uma hierarquia visual clara e se as informações principais poderiam ser compreendidas rapidamente.

Nos testes registrados no projeto, 100% dos usuários conseguiram localizar a barra de busca e a biblioteca reorganizada no primeiro acesso.

Iterações

Os feedbacks dos usuários foram utilizados para realizar melhorias no protótipo.

Algumas alterações incluíram:

- Aumento do tamanho do botão de fixar playlist;
- Reintrodução da seção de músicas tocadas recentemente;
- Ajuste do contraste do botão de Play;
- Padronização do ícone de perfil e configurações.

 Ferramentas

- Figma — wireframes e prototipagem;
- ChatGPT/Gemini — apoio na organização textual e estruturação de ideias;
- UX/UI Design — análise e desenvolvimento da interface.

A Inteligência Artificial foi utilizada como ferramenta de apoio, enquanto as decisões de design foram realizadas pelo grupo.
